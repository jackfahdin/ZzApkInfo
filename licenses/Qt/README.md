# Qt 运行库

本应用使用动态链接的 Qt 6 Core、Gui、Widgets、Svg、Concurrent 及部署工具复制的插件。Qt 开源许可正文随此目录分发；实际组件与第三方依赖的完整通知以所用 Qt SDK 为准。

Qt 项目：https://www.qt.io/
Qt 源码与相应版本：https://code.qt.io/cgit/qt/
Qt 6.8.3 源码包：https://download.qt.io/archive/qt/6.8/6.8.3/single/

Qt DLL 保持可替换，不将 Qt 静态链接进本应用。此目录的 LGPL-3.0 与 GPL-3.0 标准许可证正文来自本机 Qt 官方源码树。
